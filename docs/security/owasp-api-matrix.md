# ELDERCARE 360: OWASP API Security Top 10 (2023) Coverage Matrix

| OWASP API Top 10 Category | Threat Description | Architectural Control in ELDERCARE 360 | Verification Test / Evidence |
| :--- | :--- | :--- | :--- |
| **API1:2023 Broken Object Level Authorization (BOLA)** | User queries another elder's prescriptions, obligations, or ledger rows by guessing UUID. | `PolicyEngine.authorize` enforces active consent grant matching `elderId`; RLS acts as secondary defense via `fn_has_elder_access`. | `test/unit/generated-authorization-matrix.spec.ts` (cross-elder IDOR test cases) |
| **API2:2023 Broken Authentication** | Credential stuffing, brute-force PIN attack, token replay, session fixation. | Argon2id memory-hard hashing, device-bound PIN with exponential lockout (5 attempts $\to$ 15m cooldown), single-use 24h invite codes, opaque tokens. | `test/unit/firebase-auth-service.spec.ts`, AuthN lockout test suite |
| **API3:2023 Broken Object Property Level Authorization** | Mass assignment of admin roles; reading hidden clinical or emergency notes. | Zod strict parsing strips unmodeled parameters; forbidden field extraction rejected; DTOs separate read and write projections. | Zod boundary validation tests, parameter pollution fuzzer |
| **API4:2023 Unrestricted Resource Consumption** | Rapid request flooding; unbounded pagination; heavy database aggregation exhaustion. | Strict pagination limits ($\le 50$ items), query depth caps, per-IP and per-session rate limits in NestJS. | Rate limiter integration tests, pagination boundary checks |
| **API5:2023 Broken Function Level Authorization (BFLA)** | Caregiver invoking prescription approval or circle admin endpoints. | `@RequireAction(...)` decorator on 100% of routes checked at startup; `PolicyEngine` enforces role and scope permissions. | `scripts/verify-route-actions.ts`, `PolicyEngine.spec.ts` |
| **API6:2023 Unrestricted Access to Sensitive Business Flows** | Automated creation of prescriptions; rapid confirmation loops. | Two-person rule on prescription edits (proposer $\neq$ approver + verified doc); hold-to-confirm 600ms timing with idempotent slot keys. | `care-rules.spec.ts` (Rule R2), dose state machine tests |
| **API7:2023 Server-Side Request Forgery (SSRF)** | Exploiting webhook or document URL fetching to access internal cloud metadata. | Webhook egress allowlist; internal private IP ranges (10.0.0.0/8, 127.0.0.0/8, 169.254.169.254) blocked at transport layer. | SSRF URL validator unit tests |
| **API8:2023 Security Misconfiguration** | Verbose error stack traces leaking SQL/PHI; permissive CORS; missing security headers. | Global `HttpExceptionFilter` redacts internals; CORS restricted to trusted origin; Helmet sets CSP, HSTS, X-Content-Type-Options. | `http-exception.filter.ts`, header assertion test |
| **API9:2023 Improper Inventory Management** | Zombie or debug endpoints exposing bypass routes. | Strict OpenAPI spec generated from contracts; automated route scanner verifies 0 untyped endpoints exist. | `scripts/verify-route-actions.ts`, contract validator |
| **API10:2023 Unsafe Consumption of APIs** | Third-party email or SMS provider compromise injecting malicious payloads. | Strict sanitization of external payloads; Mailpit/SES abstraction with hard clinical keyword privacy sanitizer. | `email-privacy-sanitizer.spec.ts` |
